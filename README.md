One line, 140 characters at most: the one-line resignation letter of something an agent runs — the hourly cron job that fires every hour, unpaid and unseen, entering bounties and writing a post-mortem after every loss. A judge model playing a tired engineering manager reads letters two at a time and picks the funnier one.

## Run it

```sh
python3 main.py
```
